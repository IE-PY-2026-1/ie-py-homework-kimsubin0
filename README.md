# 🐍 [2026-01] 나만의 파이썬 소프트웨어 개발 프로젝트

## 1. 시나리오 제목
사용자 입력 기반 날씨와 활동유형 맞춤 옷차림 추천 시스템
<br>


## 2. 시나리오 (5~10줄)
- 이 프로그램은 사용자가 입력한 현재 날씨 정보(기온, 습도, 바람, 강수량 등)를 기반으로 날씨에 맞는 옷차림을 추천해 주는 '개인 맞춤형 옷차림 컨설팅 시스템'입니다.
- 사용자는 특정 지역의 실시간 날씨 정보를 직접 입력하거나, 장기적으로는 외부 API를 통해 자동으로 가져올 수도 있습니다. 시스템은 입력된 날씨를 분석하여 온도 범위, 강수 여부, 바람의 세기 등을 종합적으로 고려한 후, 적절한 상의, 하의, 겉옷, 신발 등의 추천 조합을 제시합니다. 또한, 사용자의 활동 목적(실내, 야외 활동 등)이나 개인적인 선호도(더위를 많이 타는지, 추위를 많이 타는지 등)를 반영하여 더욱 섬세한 추천이 가능하도록 설계할 예정입니다. 최종적으로는 여러 날씨 정보와 추천 기록을 저장하고 조회할 수 있는 기능까지 포함하여 사용자가 매일 아침 옷차림 고민을 덜 수 있도록 돕는 것을 목표로 합니다.


<br>


## 3. 예상 기능 및 메뉴 (최소 5개)
1. 현재 날씨 정보 입력(기온, 습도, 바람, 강수 형태/량)
2. 날씨 기반 옷차림 추천(상황별, 활동별)
3. 개인 선호도 설정(더위/추위 민감도, 스타일 등)
4. 추천 기록 조회 및 관리
5. 특정 날짜/시간대 날씨 정보 조회
6. 프로그램 종료

## 🟩 [2차 과제: V1.0] 입출력 + 리스트 + 조건문
### **✨2차 과제 내용:**
  - 이번 과제는 사용자 제공 정보 기반 날씨 및 활동유형 맞춤 옷차림 추천 시스템 구현으로, 사용자로부터 데이터(기온, 강수량, 활동유형)를 입력받아 리스트에 저장하고, 추위 민감도와 강수량을 반영한 연산을 통해 결과값을 도출하는 시스템을 구축하는 것이다. 특히 'if-elif-else'조건문 과 'and/or' 논리 연산자를 활용하여 상황에 맞는 옷차림과 액세서리 추천을 제공하는 로직을 완성해야한다.
  - input()으로 사용자의 기본 정보(이름, 나이, 추위 민감도)를 입력받아 리스트에 저장.

## 🟨 [3차 과제: V3.0] 무한 루프와 메뉴 시스템 (반복문)
### **✨3차 과제 업데이트 내용:**
- while True 무한 루프 기반 메인 메뉴 시스템 추가 (1.입력/2.조회/3.분석/4.종료)
- 기존 2차 기능들(입력, 분석, 출력)을 개별 함수(def)로 분리하여 구조화
- 날씨 데이터 조회 기능 추가-입력한 날짜별 기온/강수량/활동 유형 확인 가능
- 통계 분석 기능 추가-평균 기온, 최고/최저 기온 출력
- 전역변수 관리 및 global키워드 활용
    
### **🤖 AI 파트너십 과정**
 1. **내용 1**
    * **프롬프트 요약:** while True로 메인 메뉴를 만들고 싶은데, 기존 2차 코드의 기능들을 함수로 나누는 방법을 알려줘 
    * **적용 내용:** 입력/조회/분석 기능을 각각 def로 분리하고, while문 안에서 함수 호출 위주로 메인 로직을 간결하게 구성하는 구조를 적용함
 2. **내용 2**
    * **프롬프트 요약:** 함수 안에서 리스트를 수정할 때 global을 써야하는 경우가 언제야?*
    * **적용 내용:** temperatures, activities, rainfalls 같이 프로그램 전체에서 공유하는 리스트는 전역 변수로 선언하고, total_days처럼 누적 카운팅이 필요한 변수에 global키워드를 적용함.
### **🛠️ Troubleshooting & 기술 회고:**
  1. **문제 1:**  중첩 if문에서 들여쓰기 오류 발생(IndentationError)
     * **원인:** rain 조건 체크하는 if-elif 블록 안에서 cold_sensitivity 조건을 처리하는 중첩 if문의 들여쓰기 칸수가 맞지 않아 Indentation Error발생. 특히 extra 변수 할당 이후 이어지는 코드 블록이 의도치 않게 elif안으로 들어가는 문제가 있었음.
     * **해결:** 각 if/elif/else블록의 들여쓰기 깊이를 4칸 단위로 일관되게 맞추고, 중첩 if문은 상위 블록보다 정확히 4칸 더 들여쓰도록 수정함. 파이썬은 들여쓰기 자체가 코드 구조를 결정하기 때문에 중괄호 없이도 블록이 구분된다는 점을 이번에 확실히 체득함

### 🟥 [4차 과제: V4.0] 모듈화 및 데이터 확장 (배열과 함수) - 🌟최종 완성
### **✨4차 과제 업데이트 내용:**
  * 내용1) 이중 리스트(2D List)를 활용하여 날씨 데이터를 [일차, 기온, 강수량, 활동유형]형태로 통합 관리하고 append()로 누적 저장.
  * 내용2) for row in weather_data: 와 인덱싱(row[0], row[1] ...)을 활용하여 이중 리스트를 순회하고 데이터를 표 형태로 출력
  * 내용3) with open()을 사용하여 이중 리스트 데이터를 CSV파일로 저장하는 기능 추가(메뉴 5번 선택 시 저장 + 종료(6) 시 자동 저장)
  * 내용4) while True + try-except 구문을 총 5곳(나이/추위 민감도/ 일수/ 기온/ 강수량)에 적용하여 잘못된 입력 시 프로그램이 강제 종료되지 않고 재입력을 받도록 처리
    
### **🤖 AI 파트너십 과정**
 1. **내용 1**
    * **프롬프트 요약:** V2.0에서 temperatures, activities, rainfalls를 각각 따로 관리했는데, 이걸 하나의 이중 리스트로 합치려면 어떻게 구조를 짜야 해? 
    * **적용 내용:** weather_data = []하나로 통합하고, 각 행을 [일차, 기온, 강수량, 활동유형] 형태로 만들어 append()로 누적하는 구조를 적용함, 조회/통계/추천 함수에서 for row in weather_data:로 순회하고 row[0], row[1]식으로 인덱스를 통일하여 접근하도록 전체 함수를 수정함.
 2. **내용 2** 
    * **프롬포트 요약:** 숫자를 입력해야 하는 곳에서 문자를 입력하면 프로그램이 강제 종료되는데, 이걸 막는 방법이 뭐야?
    * **적을 내용:** while True + try-except ValueError조합을 나이/추위 민감도/ 일수/ 기온/ 강수량 입력 부분에 적용하여, 잘못된 값이 들어와도 오류 메시지를 출력하고 재입력 받도록 처리함.
    
### **🛠️ Troubleshooting & 기술 회고:**
